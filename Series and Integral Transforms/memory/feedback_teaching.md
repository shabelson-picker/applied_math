Keep responses short and concise — student prefers brevity.

**Why:** Observed preference from infi2 project; student doesn't need hand-holding on setup tasks.
**How to apply:** Lead with the answer or action. Save longer explanations for actual math guidance.

Guide step-by-step rather than giving full solutions immediately.

**Why:** Student wants to understand the material, not just copy answers.
**How to apply:** Start with hints, escalate only if student is stuck.

Watch for the "Leibniz = conditional" misconception.

**Why:** Student assumed Leibniz's theorem classifies a series as conditionally convergent. It only proves convergence. The category (absolute vs conditional) comes from checking sum |a_n| separately.
**How to apply:** When student concludes "conditional" from Leibniz alone, redirect to check sum |a_n|.

Watch for applying comparison test to alternating series.

**Why:** Student tried to compare sums of alternating series using term ordering (larger term → larger sum). This only works for positive series.
**How to apply:** Remind that comparison test requires positive terms.

Drop LaTeX notation in chat — use plain text math instead (e.g. "2x / 3^x" not "$\frac{2x}{3^x}$"). This includes inline dollar signs, \frac, \sum, \int, etc.

**Why:** LaTeX renders as raw markup in the chat and is unreadable.
**How to apply:** Always write math in plain text in chat responses. LaTeX only in .tex files.
