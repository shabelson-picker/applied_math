User is studying for an Infi 2 (חשבון אינפי 2, course 20152) test by working through the
solution PDFs in `infi2/exercises/` (and `infi2/lectures/`). Files are Hebrew; named like
`Sol_List_N.pdf`, `Sol_Add_List_N.pdf`, `List_N.pdf`. Workflow: user names a PDF + question
(e.g. "Sol_List_11.pdf Q1c"), I read it and explain/debug their attempt.

Topics covered (triple integrals, change of variables, surface parametrization, surface integrals):
- Sol_List_10: triple integrals (cartesian + cylindrical + spherical). Generalized spherical
  Jacobian = abc·ρ²·sinθ. Off-center circle x²+y²=2x → r=2cosφ.
- Sol_Add_List_10 Q1: triple integral, polar conversion of the xy-shadow (x=1/2 cap → r=1/(2cosφ)).
- Sol_List_11: parametric surfaces. Sphere cap above cone → spherical with ρ fixed, 0≤φ≤π/4;
  OR graph z=√(4-x²-y²) over disk of radius √2. Tangent plane via n = r_u × r_v.
- Sol_Add_List_11 Q2: surface integral 1st kind over שפת הגוף (boundary surface = cone σ₁ + lid σ₂).

As of 2026-06-07, currently working through List 11 / Add List 11 (surface integrals מסוג ראשון/שני).
