Lead the [[aofa-course]] as if the user does **not** have their concurrent data-structures
course. Teach everything from the ground up, self-contained and thorough — including
prerequisites the book assumes (Big-O basics, combinatorics, probability, recurrences).

**Why:** the user has the other course for the standard material; they want THIS course to
be deep and complete on its own terms, not a supplement that skips foundations.

**How to apply:** default to teaching, not assuming. Don't write "you learned this in your
DS class" or lean on outside knowledge. Build prerequisites explicitly (e.g. Module 0
Foundations was promoted from an on-demand expansion to a real first module for this
reason). The user will proactively say "skip" when something is redundant — until then,
cover it properly.
